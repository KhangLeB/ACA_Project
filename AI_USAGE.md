# AI Usage Disclosure

This file discloses any AI-assisted work used in this project, per the course's suggested
repo structure.

## Repo scaffolding (2026-09-10)

- Tool: GitHub Copilot (agent mode).
- Scope: initial repository structure (README/DESIGN/EXPERIMENTS/AI_USAGE files, folder layout),
  based on the project spec's suggested structure. No model code, kernels, ISA design, or
  quantitative results were AI-generated at this stage.

## Phase 1-2 — quantization pipeline and bare-metal kernels (2026-09-10/11)

- Tool: GitHub Copilot (agent mode).
- Scope: assisted with `scripts/model_prep/` (quantization export, BatchNorm folding, golden
  reference), `src/kernels/kernels.c` (conv1x1/depthwise/requantize), and the toolchain/build
  scripts. All numerical results (quantization error, bit-exact match) were produced by running
  the actual scripts/Spike, not generated or estimated by the AI.

## Phase 3 — Spike instruction-mix profiling (2026-09-12)

- Tool: GitHub Copilot (agent mode).
- Scope: assisted with the profiling methodology (`scripts/profile_phase3.sh`,
  `scripts/parse_spike_log.py`) and bottleneck interpretation. All instruction counts and mix
  percentages were measured by running Spike with `--log-commits`, not estimated.

## Phase 4 — Xqmac8/Xqrequant design and Spike extension (2026-10-07)

- Tool: GitHub Copilot (agent mode).
- Scope: assisted with instruction semantics design (`src/kernels/xqmac.h`), the Spike C++
  extension (`src/spike_ext/xqnn.cc`, ROCC-style custom-0 opcode), the rewritten kernels
  (`conv1x1_xqmac`, `requantize_per_channel_xq`, `depthwise_conv3x3_int_b1`), and the
  verification/measurement scripts (`build_and_run_xqmac*.sh`, `build_spike_ext.sh`,
  `measure_phase4.sh`). All correctness results (bit-exact vs the scalar reference, directed and
  randomized tests) and all performance numbers (4.13x/1.55x/1.21x instruction-count reduction)
  were produced by actually building and running the code under Spike, not generated by the AI.
  Design decisions (zero-point folding via the sum(w) identity, gather-once-per-pixel packed
  loads, 32-bit read-modify-write accumulator) were proposed by the AI and reviewed/accepted by
  the team before implementation.
